## 二、铺词矩阵：5 类采购意图 × 4 类品类

**只有"采购意图词"才带订单。** C 端疑问词（"X 好不好用"、"怎么清洗"）只涨曝光不涨单，且会把站点拉向低价值受众。

### A 类｜找供应商（最高价值，流量最像买家）
| 词型 | 示例 | 状态 |
|---|---|---|
| where to buy + 规格 + 场景 | where to buy 500ml stainless steel tumblers in bulk | ✅ 已做 1 篇，**可扩展 20+** |
| who makes / supplier of + 品类 | who makes OEM insulated bottles in China | 待做 |
| + 认证组合 | SGS certified bottle manufacturer China / FDA food contact bottle supplier | 待做 |
| + 定制组合 | private label water bottle manufacturer low MOQ | 待做 |
| + 交期组合 | fast lead time tumbler supplier China | 待做 |

### B 类｜规格与选型（买家在建购物清单）
| 词型 | 示例 |
|---|---|
| {容量} {品类} 规格 | 750ml vacuum flask dimensions / 40oz tumbler oz to ml |
| 材质对比 | 304 vs 316 stainless steel for water bottles |
| 场景选型 | which bottle for kids vs adults / best bottle for long haul flights |
| 冰块兼容 | can I put ice cubes in a narrow mouth flask |

### C 类｜标准与合规（采购经理必搜，转化极高）
| 词型 | 示例 | 状态 |
|---|---|---|
| AQL 抽样表 | aql chart 2.5 / ISO 2859-1 sample size table | ✅ 已做 |
| 缺陷分级 | defect classification guide drinkware / critical major minor drinkware | 待做 |
| 认证名词 | LFGB vs FDA food contact difference / what is SGS testing | 待做 |
| HS 编码 | HS code for stainless steel water bottles / China export code insulated flask | ✅ 已做 `a-hs-code-for-stainless-steel-water-bottles-importers-guide` (2026-10-29) |
| 社会责任 | am I for BSCI audit / SEDEX factory audit difference | 待做（我们能说"可按需安排"） |

### D 类｜成本与钱（决策最后一步）
| 词型 | 示例 |
|---|---|
| 模具费 | how much does a stainless steel bottle mould cost |
| 定制费 | what does custom colour printing cost per bottle |
| 运费 | FOB vs DDP drinkware China / how much to ship 5000 bottles |
| 关税 | US tariff on Chinese stainless steel bottles 2026 |

### E 类｜售后与风险（降低采购顾虑，转化被低估）
| 词型 | 示例 | 状态 |
|---|---|---|
| 保修条款 | vacuum flask warranty terms / how to claim defective bottle | ✅ 已做 |
| 质量异议 | will 304 stainless steel rust / why does my bottle leak | ✅ 已做 |
| 验厂 | what does a factory audit actually check | 待做 |
| 供应商核查 | how to verify a China supplier is real | ✅ 已有 |
| 纠纷 | what to do if goods fail AQL inspection | 待做 |

### 明确不做的（浪费流量）
- C 端疑问：how to clean / does it keep drinks cold / is it worth it / best gift for him
- 售后维修 DIY：how to fix a thermos / replace a seal yourself
- 竞品/仿牌：Stanley dupe / Owala alternative（我们已改口径不蹭大牌，且有 patent-safe 角度但不做关键词蹭牌）
- 跨品类错词：industrial vacuum tank / chemical storage container

## 三、持续机制（每周 30 分钟）

1. **GSC → 词表**：每周导出热门查询，按"曝光 × 是否采购意图"筛。规则：**曝光 > 0 且带采购意图词（where to buy / supplier / manufacturer / wholesale / bulk / MOQ / price / cost / HS code / AQL / audit / warranty）才进选题库**；其余默认丢弃。
2. **进选题库**：写进 `_content/b2b-topics.json`，字段要含 `slug / title / meta_desc / angle / faq`，并在 angle 里写清楚"这篇要给买家什么可直接抄走的东西（表/条款/清单）"。
3. **写文章**：**不要用 `_content/gen_article.py` 的固定正文骨架**（它只换标题和 FAQ，234 篇存量文章就是这么来的）。正文必须每篇独立：真表格、真条款、真计算方法。
4. **三处同步**：sitemap.xml 加 URL → llms.txt 的 Buyer's Guides 段加条目 → `_content/published_log.md` 登记（防重复发布）。
5. **标题硬规则**：title ≤ 70 字符、description ≤ 160 字符，**把目标词原样放进 title 前半段**（例："AQL 2.5 Sampling Chart for Drinkware"）。
6. **结构化数据**：每篇 Article + FAQPage(5 问) + BreadcrumbList + Organization，FAQ 用 `<p><strong>Q</strong> A</p>` 格式（与已发布文章一致，Google 才会抓）。
