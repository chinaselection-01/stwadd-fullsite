把图片放到 stwadd.com

三分钟学会，图片直接存在我们自己的网站上，永久有效、不依赖任何外部图床。全程只需一个 GitHub 账号。

为什么要这样做？ 以前图片放在别人家的图床（yfisher / UCloud 桶），对方不稳定、图可能裂。现在全部改存到我们自己的 stwadd.com，图从自己的网站发出，又快又稳，也不再给别人做嫁衣。
1

点下面这个红色大按钮

它会自动打开我们仓库里专门放图片的文件夹（images/uploads），已经帮你定位好了，不用自己找。

2

把图片拖进去，然后提交

打开后把图片文件直接拖到网页上（可一次传多张）→ 拉到页面最下方 → 在 Commit changes 上面随便写一句说明（如 add product photos）→ 点绿色的 Commit changes 按钮。等 1–2 分钟即可。

3

拿到图片链接

用下面这个工具，输入你刚传的文件名，点复制，就得到图片的公网链接了。发给我、贴在产品介绍里、放进画册都行。

🚀 打开上传页面（点这里开始传图） 会在新窗口打开 GitHub · 需要先登录你的账号 chinaselection-01

图片链接生成工具

传完图后，在这里输入文件名（含扩展名），自动生成可复制的图片地址：

https://stwadd.com/images/uploads/
完整链接会显示在这里…

文件命名规范（很重要）

  • 用英文小写 + 数字 + 连字符，例如 tumbler-40oz-red.jpg
  • 不要用中文、空格、括号 —— 否则链接会变复杂，容易出错
  • 常用格式：jpg / png / webp / svg 都支持
  • 单张图片尽量小于 10MB，网站加载更快
  • 提交后等 1–2 分钟再访问链接（GitHub 需要时间发布）
